# Dantas Prime Films

Site institucional de películas automotivas com atendimento somente por agendamento. WhatsApp e telefone: (11) 94456-4102.

Arquivos públicos em `dist/`. HTML, CSS e JavaScript sem dependências de build; sirva essa pasta em qualquer servidor estático. A configuração `vercel.json` utiliza `dist` como saída para importação na Vercel, preset Other.

O formulário monta a mensagem a partir do modelo/ano, assunto e detalhes opcionais. Abre o WhatsApp para revisão e envio pelo visitante; não armazena dados nem confirma uma reserva.

## Informações pendentes

Conforme solicitado pelo usuário, cidade e endereço usam o placeholder público “Região de atendimento a confirmar”. Nenhum mapa foi inventado. Atualizar essa seção e inserir o Google Maps quando houver endereço confirmado. Materiais, tonalidades, valores, prazos e garantia são tratados como consulta à empresa. Não foram inventados resultados, credenciais ou clientes.
